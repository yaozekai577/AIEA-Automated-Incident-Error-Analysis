================================================================
AIEA — AI 错误根因分析与工单自动化平台
================================================================

【一句话简介】
把“异常捕获 → 智能去重 → AI 根因分析 → 群聊通知 → 工单闭环”全流程自动化，
替代人工翻日志—群里同步—手填工单的低效模式，缩短故障响应时间（MTTR）。

【怎么跑起来】（详细步骤见 相关文档/README.md）
1. 建库：MySQL 执行 数据库/init（mysql）.sql
2. 装 SDK：cd 源码/aiea-sdk && mvn clean install -DskipTests
3. 起后端：cd 源码/AIEA && mvn spring-boot:run
4. 起前端：cd 源码/frontend && npm install && npm run dev
   访问 http://localhost:3000 ；Swagger：http://localhost:8080/swagger-ui.html
   环境要求：JDK 17 / Maven 3.8+ / MySQL 8 / Redis 6+

【需要注意】
- 本版本无需登录，打开即用，所有访问者权限一致
- 大模型(LLM)与飞书/钉钉需自行配置 Token/Webhook 后才触发分析与推送
- Jira 为可选集成，未配置不影响内置工单功能
- LLM 调用失败时自动降级为规则摘要，不影响主流程

【亮点速览】
堆栈指纹去重不刷屏 · 异步流水线(分析→建单→通知) · 多通道通知路由 ·
零侵入接入(SDK/Logback) · 内置工单不依赖 Jira · 敏感信息双层脱敏
